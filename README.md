SOLBAY — the most complete open-world crime game an agent can build in the spirit of GTA 6: a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, and a HUD with a minimap. Built with three.js, plays offline in a desktop browser from its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
